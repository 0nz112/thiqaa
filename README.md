# منصة ثقة — بوت تيليغرام + Mini App

البوت لا يستلم أموالاً. الإيداع والتحويل يتمّان خارجياً، والبوت يحفظ بيانات الأعضاء وأرصدتهم،
ويستقبل طلبات السحب وتصفية الحساب، وينشر السحوبات بعد تنفيذها.

## ما يراه العضو
- **حسابي ← البيانات الشخصية:** الاسم الثلاثي، رقم الهاتف، نوع الحساب (زين كاش / كي كارد / مصرفي)، رقم الحساب. مشفّرة.
- **المحفظة:** الرصيد المتاح، المستثمر، الأرباح المحققة، مكافآت المهام، وزرّان: **طلب سحب أرباح** و**تصفية الحساب**.
- **سحوبات الأعضاء:** كل سحب نفّذته الإدارة (واسمه مختصر)، مع إشعار فوري داخل التطبيق.
- الاستثمار، المهام، سجل العمليات، التقرير المالي، صفحة الشفافية، ورابط الإحالة.

## دورة طلب السحب
1. العضو يضغط «طلب سحب أرباح» (بمبلغ) أو «تصفية الحساب» ← يُحجز المبلغ.
2. يصل للمشرف إشعار فيه: الاسم، الهاتف، نوع ورقم الحساب، المبلغ.
3. المشرف يراجع ويحوّل خارجياً، ثم يضغط **«تم التحويل — تسجيل البيانات»** ويرسل: `المبلغ | رقم الإيصال`
4. يُخصم من رصيد العضو، يصله إشعار برقم الإيصال، ويُنشر السحب في صفحة السحوبات (والقناة إن وُجدت).
   أو يضغط **«رفض»** فيعود المبلغ لرصيده.

في التصفية يحدد المشرف المبلغ النهائي المحوّل؛ تُغلق الاستثمارات النشطة ويُسجَّل الفرق ربحاً أو خسارة.

## أوامر الإدارة (أرسل /help في البوت)
```
/pending                           الطلبات قيد المراجعة
/paid رقم_الطلب المبلغ رقم_الإيصال   تسجيل تحويل (بديل الزر)
/user ID                           ملف عضو ورصيده
/deposit ID المبلغ ملاحظة            تسجيل إيداع تم خارجياً
/profit ID المبلغ ملاحظة             إضافة ربح لعضو
/stats
/extpayout الاسم | المبلغ | الطريقة | الإيصال     سحب نُفّذ على منصتك السابقة
ملف CSV مع التعليق /import_payouts               قائمة سحوبات اليوم من المنصة السابقة
/addtask  /addproject  /pstatus  /settle  /kyc  /freeze  /unfreeze
```
معرّف العضو (ID) يظهر في إشعارات الطلبات وفي /user.

## النشر على Railway من GitHub
1. ارفع المشروع إلى مستودع **خاص** على GitHub.
2. Railway: New Project ← Deploy from GitHub repo.
3. Variables: `BOT_TOKEN` (والاختيارية من `.env.example` إن أردت).
4. Settings ← Networking ← **Generate Domain**.
5. أضف **Volume** على المسار `/app/data`.
6. من Deploy Logs انسخ `/admin ……` وأرسله للبوت لتصبح المشرف.
7. في BotFather: `/setinline` (لزر مشاركة الإحالة).

## التشغيل على جهازك للتجربة
ثبّت Node.js، ضع `BOT_TOKEN` في ملف `.env`، وشغّل `start-windows.bat`.

## ملاحظات
- سجل التدقيق والسحوبات المستوردة غير قابلة للتعديل أو الحذف.
- السحوبات المستوردة من المنصة السابقة تُقبل فقط بأوقات مضت ورقم إيصال فريد، وتظهر بشارة المصدر.
- انسخ مجلد البيانات احتياطياً بانتظام (على Railway: الـ Volume).
